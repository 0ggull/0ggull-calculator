# 0GGULL — 인생 큰 결정 전, 숫자로 먼저 따져보기

반려동물 · 자동차 · 아파트 · 자녀 — 인생의 빅 이벤트 비용과 기회비용을 숫자로 시뮬레이션하는 계산기 모음 사이트입니다.

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행
npm run dev

# 3. 브라우저에서 열기
# http://localhost:3000
```

## 빌드 & 배포

```bash
npm run build
npm start
```

Vercel 배포 시 별도 설정 없이 Git push만으로 자동 배포됩니다.

## 기술 스택

- **Next.js 14** (App Router)
- **Tailwind CSS** (다크/라이트 모드)
- **Recharts** (차트)
- **Lucide React** (아이콘)
- **html2canvas** (SNS 영수증 이미지 저장)

## 계산기 목록

| 페이지 | 경로 | 설명 |
|--------|------|------|
| 반려동물 생애비용 | `/pet` | 소형견/중형견/대형견/고양이 15년 생애비용 + S&P500·나스닥 기회비용 |
| 자동차 vs 대중교통 | `/car` | 차량 소유 총비용 vs 택시+대중교통+쏘카 대안 비교 |
| 아파트 매도 BEP | `/apartment` | 취득세·이자·복비·양도세 고려한 본전 매도가 계산 |
| 자녀 양육비 | `/child` | 출산~대학졸업(22년) 연령별 양육비 시뮬레이션 |

- 모든 수치는 **2024년 기준 평균값**이며 참고용입니다
